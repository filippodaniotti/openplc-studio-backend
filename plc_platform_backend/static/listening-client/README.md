# Third-Party Modified Version of the webMUSHRA Software

Modified by PLC platform on **2026-10-06**. Original AudioLabs copyright and full
license notices are retained. This is not an endorsed AudioLabs/Fraunhofer release.
Upstream commit: `8c353f738aa88fa9dee0dc1aa7d18d2a06441cb5`.

The native, keyboard-accessible renderer replaces the legacy page manager and
synchronous sender, while retaining webMUSHRA's synchronized audio switching,
short fades and looping engine. It consumes the YAML/WAV bundle generated by
HumanCalculator. Anchors are prepared by the core, never synthesized differently
in the browser. Assigned trial/condition orders are immutable and never shuffled
again on reload. Untouched sliders remain unanswered; zero is a valid answer.

Saves are complete accumulated rating snapshots, serialized and acknowledged by
FastAPI before advancing/finishing. Exact pending requests and newer edits are
retained in per-tab IndexedDB; bearer invitation tokens are never stored there.
Conflicting revisions require explicit reload, never an automatic overwrite.
The native UI loads only the current trial, at most three files concurrently and
64 MiB of decoded mono/stereo audio. Unsupported playback/storage capabilities
are reported. Chrome/Edge desktop is the primary playback target; actual audio
context rates (including resumed sessions on different devices) are recorded.

Changes to `MushraAudioControl.js`: remove accidental global references, apply
pending fade-position resets, and zero non-looping buffer tails. Original source
and all original third-party notices are included in `source.zip`, together with
the deployed modified sources and Angular host. Recipients can obtain it free of
charge at `/api/listening-client/source.zip`. Do not charge copyright-license fees
for this software. Patent licensing, if applicable, remains the user's responsibility.

No PHP, pyMUSHRA, telemetry, demographic questions or separate server is used.
HTTPS (or browser localhost exception) is required. Deployments must protect owner
management APIs independently; participant tokens do not implement owner auth.
Do not gate the participant or free source-download routes behind owner-only access.

Regenerate the source archive after edits, from the backend repository:

```sh
python scripts/package_listening_client_source.py --upstream ../webMUSHRA
```

`LICENSE.txt`, `THIRD-PARTY-NOTICES.txt` and `vendor/yaml-LICENSE.txt` contain the
complete applicable notices. The original upstream sources are included unchanged
under `upstream-original/`; deployed modifications are under `modified/`.
